# Дома и бани из бруса и бревна — статический сайт

Статический сайт (HTML + CSS + JS + галереи Highslide), размещён на бесплатном хостинге **GitHub Pages**.

**Адрес сайта:** https://kristikrissi.github.io

## Структура

- `index.html` — главная страница
- `*.html` — остальные страницы сайта
- `shared/` — скрипты и графика галереи Highslide
- `*.jpg`, `*.png` — изображения (в т.ч. файлы с суффиксами `.1`, `.2`, `.3` — они реально используются страницами, не удалять!)

## Публикация

Сайт публикуется из ветки `main` автоматически через GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / root).

## Локальный запуск

Открыть `index.html` в браузере или запустить простой сервер:

```
python -m http.server 8000
```
